Millions of Marathi records were written in Modi, a script almost no one can read today. BhashaYantra reads them into Devanagari and marks every word it isn't sure of, so a human checks what matters.

The problem

4,00,00,000

Modi documents are still unread: land grants, court records, letters, medicine. The language is still spoken; the script is no longer taught. Only a few experts can read these pages today.

Source: Kausadikar et al., ICDAR 2025 (MoScNet).
